# 包包 V1.0

首个供朋友试用的 Windows x64 运行包。

下载 `Baobao-v1.0-windows-x64.zip`，完整解压后双击 `Baobao.exe`。请保留旁边的 `Baobao.exe.config`；`玩具` 文件夹有猫抓板和柱形猫爬架。

- 半写实暹罗猫包包，带自然待机与轻量诉求气泡。
- 长按轻移抚摸，侧头、闭眼、单耳、尾尖与轻呼吸相互配合；Alt 拖动移动。
- 光点陪玩、吃粮、喝水和动作完成反馈。
- 普通文件拖到双碗会真实进入系统回收站；专用玩具拖到猫身则保留文件并触发互动。
- 包包头像托盘图标，支持隐藏、找回、穿透和暂停。

试用与反馈：[README](https://github.com/baotu4/baobao-desktop#readme) · [提交问题](https://github.com/baotu4/baobao-desktop/issues/new/choose)。初次投喂请使用专门创建的无用测试文件。

目标环境为 Windows x64、.NET Framework 4.8。混合 DPI 多屏切换等尚未专项实测，具体范围见仓库 `docs/TESTING.md`。
