# 朋友试用反馈

先从 Releases 下载并解压运行包，启动 `Baobao.exe`。准备一个无用测试文本后，再体验投喂。

建议试试：长按轻移抚摸、Alt 拖动、右键陪玩、分别拖入猫抓板和猫爬架、测试文本投喂、隐藏后从托盘找回。

反馈时记录下面几项即可：

- 版本：V1.0。
- Windows 版本、屏幕缩放比例、是否使用多个显示器。
- 发生在哪个动作，做了什么操作，是否每次都能复现。
- 预期效果和实际表现。
- 若是动画问题，指出身体哪个部位、什么时候跳动/重影/遮挡。

可以附只包含包包的短录像或截图。文件投喂问题请用无用测试文件复现，描述类型即可。

如包包找不到，先双击托盘猫头像，或再次启动程序；右键菜单也有恢复位置和大小。
